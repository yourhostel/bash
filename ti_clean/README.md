# ti_clean

## Скрипт для очищення .vtt субтитрів

Скрипт видаляє службову інформацію з .vtt файлів субтитрів, залишаючи лише чистий текст діалогів. Він прибирає:

- службові рядки на кшталт `WEBVTT і X-TIMESTAMP-MAP`
- таймкоди `(00:00.000 --> 00:02.000)`
- позначки звуків типу `[Music]`
- Об’єднує весь текст в один рядок.
- Розбиває його на абзаци по реченнях (кожна нова фраза з великої літери після крапки переноситься на новий рядок)

Приймає файл параметром:
```bash
ti_clean <file>.vtt
```
Файл повинен бути у `/home/<your user>/Desktop`
Повертає в туж саму директорію `/home/<your user>/Desktop` приєднуючи до назви вхідного файлу `clean_<назва>.txt`
```bash
OUTPUT="$DIR/clean_${BASENAME}.txt"
```
